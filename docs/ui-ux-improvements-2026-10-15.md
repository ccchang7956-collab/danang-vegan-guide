# UI／UX 優化交付紀錄（2026-10-15）

## 完成內容

依 [review](ui-ux-review-2026-10-15.md) 的使用影響安排順序，沿用既有靜態網站與配色，新增 `assets/ux.js` 管理介面偏好、收藏、採買、導覽與輔助操作。

1. 搜尋欄旁持續顯示結果數與參考位置；輸入即搜尋，按 Enter／手機搜尋鍵查看結果並顯示 toast。零筆可直接清除、擴大範圍或重設。
2. 「只看全素」保留關鍵字、區域與營業查核；可移除條件摘要、重設、距離／全素排序。營業查核收進進階區。
3. 點餐頁操作前移，第一屏可放大與複製越南文；英文與中文按需展開。
4. 手機附近素食與換匯預設列表，可切地圖，並從地圖返回剛才卡片。桌面維持並排。彈窗限制尺寸，選取圖釘立即定位，避免縮放動畫與自動移動畫面互相干擾。
5. 卡片優先呈現飲食條件、評分、地址、參考時段與導航；每週詳情與研究說明可展開。蛋奶、地址衝突、歇業、休息日與個別風險維持直接可見。評分來源類型與非即時狀態仍有標示。
6. 每日整天行程距離顯示最近地標名稱；縮短手機頁首。旅行期間以越南日期預選當天，網址指定日期優先。
7. 切換入口保留各頁閱讀位置，同頁重按回頂端；hash 支援頁別、日期分享和瀏覽器返回。跳轉卡片／列表同步移動焦點，收藏重新繪製後恢復焦點。
8. 換匯先選幣別，推薦說明可展開，仍區分銀行層級資料和分行實際受理。
9. 新版更新使用常駐可關閉橫幅；關閉後可從頁首再次開啟。重新載入保留每日、附近、換匯的非 GPS 條件。
10. 超市商品採站內圖片放大、複製越南文名稱、成分展開與「已買到」勾選；修正過期六款文案。
11. 新增本機餐廳收藏、只看收藏與採買狀態；儲存失敗仍可當次使用並告知。GPS 不寫入偏好、網址或更新還原資料。
12. 匯出與整體查核說明移到獨立展開區。調整徽章、評分與次要文字層級；新增控制字級／高度變數。未做整份舊 CSS 的無關重寫。
