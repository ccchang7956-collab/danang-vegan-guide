# v23 審查後優化（2026-10-16）

## 修改

- 搜尋支援「會安全素早餐」等已知詞連寫；完整切分才採語義條件，保留未知中文菜名及英文店名的字面搜尋。全素意圖仍依既有飲食分類與所選日期比對。
- Handy 移除官方成分頁不支持的「乾燥豆腐」；AEON 說明改為目前 11 款商品，未宣稱分店有庫存。
- 超市商品與門市 HTML 改由 `research/supermarket-supplies.json` 生成，接入 `scripts/build-data.py`。renderer 檢查來源 URL、圖片存在、尺寸、ID 衝突並 escape 文字；`--check` 可偵測頁面漂移。
- 門市卡片不加入商品的採買與複製操作；11 個商品採買項目維持原功能與 ID。
- 正式站驗證明確要求來源／目標版本，保留真正舊版的 scope、cache、runtime 與收藏證據；更新後核對網路與快取 SHA256、收藏及離線。缺失或錯誤證據會失敗，不再只靠輸出標籤宣稱版本升級。
- 加入 GitHub Actions：Node 測試、格式、超市同步與生成結果檢查。瀏覽器回歸在本機另行執行。
- 離線版號 v23，交付 ZIP 同步。沒有增加網站執行時相依套件。
