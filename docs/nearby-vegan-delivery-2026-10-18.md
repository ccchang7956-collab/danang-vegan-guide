# 一鍵附近全素改版交付

日期：2026-10-18。功能於 v29 完成；正式站已發布 v30，另修正升級沿用舊 HTTP 快取的問題。本機程式與 ZIP 同步。見[正式發布與升級驗證](nearby-vegan-live-release-2026-10-18.md)。

## 操作方式

新開首頁、且沒有指定頁面或既有返回狀態時，先進入「附近全素」。點「找我附近的全素」後，網站套用全素、越南當日當下、3 km，取得位置並顯示候選。首次需允許瀏覽器定位。

先顯示最多三間依牌告時段可用餐的候選，其餘候選可展開；即將結束／供餐需確認、其他時段與距離未確認的店分組保留。清單僅來自本站收錄，不代表附近所有餐廳。牌告時段並非即時接單保證，距離皆為直線。

沒有結果時可擴大至 5 km、再至 10 km，仍保留全素。也可使用「改用飯店／景點」。搜尋、收藏、Grab 與更多規劃條件可展開使用。底部依附近、行程、點餐卡、補給、換匯排序。

定位成功後主按鈕收斂為「更新位置與時間」。查詢或定位超過五分鐘提示更新，返回頁面不會無聲重排正在閱讀的店家。定位拒絕、逾時、誤差超過 1 km、位於峴港／會安約 150 km 範圍外，都顯示明確狀態；現在模式定位異常時，地圖也不顯示可靠附近候選的假象。

## 返回、離線與資料

- 明確的行程／日期連結維持優先；一般重載與切頁保留搜尋與閱讀目標。
- 展開後的候選群組會保留，地圖也可直接返回原本收合群組中的店家。
- GPS 從不寫入儲存。若重載後原店家不在備案飯店範圍，另保留「上次查看的店家」，明示需更新位置確認距離，不計入附近結果數。
- 地圖在切換或實際需要時才初始化；單純進附近列表不請求圖磚。
- 沿用離線快取、點餐卡、收藏、補給與原店家查核資料。Google Maps／Grab／外部來源仍需連線。
- 保留工作目錄原有的 Grab 更新。原本硬編碼 10/17 的測試改為對照研究 JSON 的逐店實際查核日。

## v30 發布補充

Node 全部 126 項通過；新增 HTTP 快取回歸後，Chrome 與 WebKit 各三項離線／升級測試通過。正式站從原 v27 升級失敗的 Chrome 狀態繼續驗證 v29 → v30，確認應用資產與快取 SHA256 一致、收藏保留、離線重開、附近首頁、受控 GPS 與離線點餐卡通過；全新 WebKit 亦通過。這些是 v29 完整測試之後的發布驗證，並未宣稱重新執行所有瀏覽器套件。
