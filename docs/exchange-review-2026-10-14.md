# 換匯頁更新與 review

日期：2026-10-14。依使用者要求更新前次研究所推薦的網站清單，同時修正頁面問題。

## 更新清單

維持 6 個有官方銀行／商場授權依據的據點。新增推薦用途、推薦來源、營業時間限制及各項資料查證日期。台灣 Outo 推薦的是峴港市區的 Vietcombank 銀行，沒有指定本頁的分行；首頁指引與卡片已明確區分。AEON 有商場正式授權公告，但沒有足夠台灣旅客直接推薦；BIDV 台幣現鈔資料屬銀行層級，分行當日服務須確認。

Soạn Hà、GO!、Vincom、樂天與相似名稱 Kim Yến 金店仍缺足以核驗的現行授權，不加入已確認清單。完整來源與研究限制見 [再查證紀錄](../research/exchange-recheck-2026-10-14.md)。

## 問題與修正

| 問題／影響 | 修正 |
| --- | --- |
| 選單一景點後卡片仍寫「距行程最近」 | 同步顯示 GPS、整天最近地標或所選景點名稱 |
| GPS 模式下參考位置仍選著「當天行程路線」，難以選同一選項切回路線 | 選單新增「我的 GPS 定位」，定位後實際選取，能切換回路線／地標 |
| 先取得 GPS，再改日期，第一次進換匯頁重新套用 GPS，蓋過日期選擇 | 手動切日期即確定換匯使用新日期路線 |
| GPS 存在時改日期未更新定位失敗備援；GPS 失敗後附近餐廳退回前一天／錯誤城市飯店 | 切日一律更新備援飯店，GPS 仍可保留作目前附近排序來源 |
| 幣別篩選清單變了，地圖卻沒有重設可見點位範圍 | 篩選後重新 fitBounds，保留當前距離參考地標 |
| 換匯頁有行程景點與飯店圖釘，卻隱藏相關圖例 | 依目前 GPS／路線／地標模式及實際點位顯示相關圖例 |
| 缺參考位置座標時，卻把有座標銀行說成「尚無可靠座標」 | 區分據點缺座標與參考位置缺座標 |
| 銀行有幣別資料易被當成分行當日一定收鈔；未列幣別易被當成拒收 | 徽章、篩選與提示明示銀行層級／資料待確認；未列幣別不代表拒收 |
| 全部卡片沿用整體更新日期，無法辨識地址與幣別哪項重查 | 分別顯示 addressCheckedDate／currencyCheckedDate，保留舊查證日期 |
| 手機須先滑過地圖才能看換匯清單 | 增加「查看換匯列表」快速跳轉；距離文字與推薦框允許換行 |

## 實測限制

可讀取 Chrome 的既有正式網站頁面，但切換測試分頁時工具因使用者同步操作而在動作前阻擋；沒有完成更新版瀏覽器、手機布局或實體 GPS 實測。自動化 UI 測試採本專案既有 DOM／Leaflet harness，驗證狀態、文字、列表、圖釘與地圖視野計算，不代表真實瀏覽器視覺檢查。沒有致電銀行／商場，也沒有把資料當成即時營業或即時匯率。

本次更新本機專案與部署 ZIP，尚未推送或部署至 GitHub Pages。
