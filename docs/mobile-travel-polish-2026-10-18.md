# 手機現地操作優化交付（v27）

日期：2026-10-18。依 [手機 review](mobile-ui-ux-review-2026-10-18.md) 及使用者核准方向實作。

## 已完成

- 一般重新整理保留搜尋、篩選、用餐日期／時間與正在看的卡片。指定 URL 日期優先；無指定日期可恢復原查詢，跨越越南午夜會提示舊時間。
- 收藏與採買資料沿用原儲存格式；另保存飲食偏好。初始化不覆寫使用者的全素選擇。GPS 座標不寫入 URL、localStorage 或 sessionStorage。
- 首次直接進站的每日地圖有返回按鈕；跳轉以整個地圖工具列對齊。每日頁回到行程，店家頁可回剛才店家。
- 餐廳與換匯的主要導航提前；不影響飲食、營業、地址衝突與山區風險警告。
- 「現在找吃的」帶入越南日期／時間、全素，清除關鍵字、區域、Grab 與收藏等相衝條件；依現有參考位置及牌告時段排序，不宣稱即時開門。
- 位置來源直接顯示，GPS 提供取得時間、精度及五分鐘後的更新提示；每分鐘及返回頁面時更新文字，不連續追蹤定位。
- 每日增加住宿導航與用餐捷徑；三餐可分別展開，跳轉能打開收合的祖先區塊。巴拿山的總體風險與下山提醒仍直接可讀。
- 每日地圖先放行程與用餐首選，可勾選其他餐廳；從未預設顯示的餐廳卡片進地圖，也能顯示其圖釘並返回。
- 更多篩選加入「查看 N 間結果」，位置／半徑／排序按需展開。收藏按鈕改為「只看收藏（數量）」語意。
- 商品卡改小圖，保留放大包裝、越南文複製及成分說明；新增未買／已買、需要熱水／直接吃的交集篩選與空結果恢復。
- 點餐卡提供完整說明／原句分行，越南文未翻譯或刪除限制；橫向按可用高度調整字級。
- 離線狀態改短字，詳細說明以可關閉面板呈現；離線開外連時留下名稱及可複製連結。
- 底部入口名稱統一，Grab 短標籤改為「Grab 入口」，避免暗示即時可接單。

## 手機版面量測

獨立 Chrome，390 × 844 CSS px，預設資料與字型。數值是主要導航按鈕的頂端：

| 頁面 | 修改前 | v27 |
| --- | ---: | ---: |
| 找餐廳 | 約 934px | 約 691px |
| 換匯據點 | 約 1187px | 約 683px |

兩頁首筆導航都能在第一屏操作。另以增加 34px 底部導覽佔位檢查，首筆導航底端仍在導覽列上方；此為佔位模擬，不是實體 iPhone safe-area 實測。

五頁在 320／393／430px 直向與 852px 橫向檢查水平溢出、控制項及閱讀流程；主要導航高度至少 44px。實際裝置字體、瀏覽器工具列及系統文字大小仍會影響排列。

## 審查與修正過程

重載保存、首次地圖返回、新功能與導航高度均先執行失敗的驗收，再修正。獨立程式審查指出三餐祖先收合、原始 URL 日期判斷、初始化覆寫飲食偏好的問題，均另以 Chrome 回歸案例重現並修正。另增加跨午夜舊時間、非首選店家地圖跳轉及離線外連驗收。

修改範圍為 `index.html`、`assets/app.js`、`assets/ux.js`、`assets/mobile.css` 與 `sw.js`，沿用原資料與生成區。既有測試同步調整按需展開控制項的操作和名稱，沒有移除原功能驗收。

## 交付狀態與實測界線

快取版本 v27，README 與部署 ZIP 一併更新；尚未 commit、push 或部署。

Chrome／WebKit 都使用獨立自動化瀏覽器，GPS 回應受測試控制；圖磚在回歸測試中以本機圖片取代。離線與 worker 生命週期使用真實瀏覽器機制。WebKit 不等於實體 iPhone。未驗證越南現地 GPS、真實軟鍵盤與 Google Maps／Grab App 交接，也未將本機 worker 驗證當作正式站部署證據。

出發前以自己的手機開啟已更新網站，確認版本更新後用飛航模式重載，再走一次收藏餐廳 → 點餐卡 → 恢復連線定位 → 導航／Grab → 返回原店家的流程。
