# 手機現地操作優化設計

依使用者核准的 `docs/mobile-ui-ux-review-2026-10-18.md` 執行。

- 延用純靜態頁與原有樣式，使用 app.js 管理旅行查詢、ux.js 管理閱讀與偏好；不引入套件。
- 一般重載與離開頁面時保存非 GPS 查詢、閱讀位置、店家目標；sessionStorage 恢復本分頁，localStorage 僅保存原有偏好與飲食選擇。日期時間跨日顯示上次查詢提示；URL 日期優先。
- 首次地圖有返回，跳轉保留整個工具列；每日預設只顯示景點／住宿與用餐首選，可展開其他餐廳。從卡片進地圖仍能找到原店家。
- 餐廳主要控制保留搜尋、位置、定位、全素／Grab／收藏，半徑與排序移入更多篩選。換匯的日期與位置收合；卡片主導航移至決策所需資訊後，地址與參考菜單在其後。
- 位置來源持續可見，GPS 顯示取得時間及過舊提示；只按需定位，不持續追蹤、不保存座標。
- 現在找吃的套用越南時間、全素，清除不相容的關鍵字／區域／Grab／收藏；保留目前參考地標或已取得的 GPS。語意為依牌告排序，非即時營業。
- 每日提供今晚住宿導航及下一餐入口；三餐可個別收合，當日依越南時間選預設餐，非當日預設午餐；巴拿山的重要警告仍直接可見。
- 篩選有查看結果入口；收藏開關保留「只看」語意；補給提供未買／已買及熱水／直接吃篩選，保留包裝放大及成分提醒。
- 點餐卡加入完整／重點分行切換，使用原有越南文原句拆分，不翻譯或刪除限制；橫向依高度調整字級。
- 離線狀態縮短，詳細限制以可關閉對話框顯示；離線點外部連結提供目標名稱及網址，可複製，保留原始連結供網路恢復後使用。
- 網站修改後更新 worker 至 v27，更新 README 與部署 ZIP；不自動部署。

驗收：重載與跨日恢復、地圖首次返回與指定店家、GPS 過舊、現在用餐、首筆導航高度、採買篩選、點餐內容完整、離線閱讀與更新流程。Chrome 四種尺寸；可用時加 WebKit。
