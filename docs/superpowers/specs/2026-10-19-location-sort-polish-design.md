# 定位、排序與搜尋呈現修正設計

使用者已同意依本輪 review 修正，並授權安排順序。採直接修正既有流程，不新增相依套件。

1. 餐廳與換匯使用同一 GPS 品質判斷：距峴港中心超過 150 km、精度超過 1000 m 或無有效座標／精度時，顯示「定位待更新」，清空對應列表與地圖圖釘；可重新定位或明確改用行程／地標。換匯手動參考位置仍可使用；不能因無效 GPS 影響每日行程地圖。
2. 預設排序改標示為「供餐時段優先」（值 recommended）。「距離優先」真正依距離遞增；「全素優先」先列全素，再依距離；無距離資料一律另列。推薦排序保留既有營運證據、時段與距離規則。附近現在模式預設推薦排序；手動改排序離開精簡模式。舊版 session 的 distance 值遷移為 recommended，保留原查詢意義。
3. 一般搜尋在推薦排序且有有效用餐時間時，使用既有供餐分類顯示「可用餐／需確認／其他時段／位置待確認」標題。每組全部展開；距離與全素排序不再分供餐群組，避免破壞所選排序。
4. 附近摘要只顯示一次日期與時間，將有距離資料與位置待確認數量分開。保留「找到 N 間」總數，位置不確定者不計入附近範圍；排序意義在摘要中可見。
5. 換匯卡將服務時間提醒移到導航前，合併重複確認文字；AEON 明示商場時間不等於櫃檯時間。
6. 首張導航保留手機底部安全區。將餐廳列表／地圖切換併入結果標題列，換匯結果列縮減空白，不縮小字級或 44px 操作目標。
