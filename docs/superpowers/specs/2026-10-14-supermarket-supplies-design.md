# 超市補給

使用者要求將前輪六款素食商品整理進專案，並新增底部入口，名稱由代理決定。採用「超市補給」，與現有每日行程、附近素食、換匯所、全素點餐並列。

用靜態 HTML 呈現六張商品卡，依泡麵與零食分組；保留中文與越南文名稱、查核依據、配方限制、來源及庫存未確認提示。提供三組採買據點與越南文成分速查，不引入即時庫存或遠端圖片相依。只把 Acecook 明確全素聲明標為品牌明確全素；其他商品按成分判讀或待確認展示。

導覽切換加入 supplies；補給頁不重新搬移地圖。五個手機導覽按鈕等寬，點餐標籤縮為四字並保留完整無障礙名稱。現有離線機制快取 HTML，版本更新 v13。同步 README、研究 JSON 与部署 ZIP。

## 包裝圖片增補

使用者要求每款商品圖片直接放入頁面。六款下載自現有官方／超市來源，縮為不超過 600px 的 WebP，保留原始包裝與商家水印。商品卡上方顯示完整圖片，可点圖開本地圖片放大。圖片來源與規格寫入研究 JSON；腰果圖片 260g 與商品頁 280g 不一致、菠蘿蜜為 500g 與 Oreo 運動版包裝均在圖說註明。六圖加入離線預快取，版本 v14。

## 食品擴充

依使用者後續要求，新增五款 LOTTE 有成分資料的即食零食：Choice L 地瓜脆片、Choice L 原味海苔、bibigo 傳統海苔米餅、L’angfarm 芋頭脆片與鳳梨乾。來源配方未列動物成分，標示依公開成分判讀，非全素認證，且分店庫存未確認。保留圖片與來源；排除資料矛盾或含奶的米餅、麵包。共 11 款含圖片，離線版本 v15。
