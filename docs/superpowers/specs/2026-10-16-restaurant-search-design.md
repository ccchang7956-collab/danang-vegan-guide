# 素食餐廳搜尋優化

使用者已同意 2026-10-16 檢視提出的五項改善，直接依既有版面實作。

- 搜尋加入中文區域、料理同義詞、全素語意條件；料理僅由既有資料支持，餐別搜尋按牌告時段推估並說明。
- 將每週時段轉成可驗證的結構。來源衝突及農曆例外用結構化警示，卡片直接可見，適用日不宣稱可用餐。
- 每日頁可選預計用餐時間，附近頁可選日期及時間，提供填入越南現在時間。判斷含午休、休息日、半小時內結束、未知與爭議；均非即時營業狀態。
- 附近頁增加 1/3/5/10 km/不限，預設不限；無座標另列且不冒稱範圍內。條件摘要、清除、空結果、更新還原同步。
- 每餐設定相關行程地標及時間，按鈕帶入附近頁日期、時間、全素、地標及 5 km；巴拿山提供園內需確認的搜尋入口，不把市區備援當山頂附近。
- 保持純靜態、無新執行相依、GPS 不持久化。重建資料、同步 ZIP、提高離線版本。

驗收：中文會安/美溪、料理同義詞、全素條件；每週時段、邊界、午休、跨午夜、越南日期；衝突警示；半徑與未知座標；每餐連結；重設與更新條件；既有 Node 與瀏覽器回歸。
