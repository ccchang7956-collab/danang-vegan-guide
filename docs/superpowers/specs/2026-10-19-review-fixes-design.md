# 2026-10-19 Review 修正設計

依使用者同意的 review 結果，修正三個已重現問題並完成兩項定向優化。

- 定位有效性獨立於「附近現在」模式：GPS 精度不足或不在旅遊區時，附近列表、摘要與地圖一律顯示定位待更新。調整日期、時間、飲食或收藏不能繞過限制；改用地標或重新定位成功後恢復正常結果。GPS 維持只存在記憶體。
- 搜尋條件仍依既有日期規則還原；閱讀位置、焦點與返回店家只還原到原頁面。指定不同頁面的網址由頁首開始，同頁重載保留原閱讀位置。
- 列表模式在桌面與手機均隱藏地圖，明確點地圖時再初始化；避免空白區塊，也保留地圖按需載入。
- 收藏操作同步同店所有卡片按鈕與收藏數。只有附近頁啟用收藏篩選、取消收藏會移除結果時才重繪附近結果與地圖；其他情況保留 DOM、展開狀態及焦點。
- CI 加入獨立 Chrome 與 WebKit job，安裝對應 Playwright 瀏覽器、執行現有全套瀏覽器測試並保留失敗診斷。

驗收：先讓新增瀏覽器回歸測試在舊程式失敗，再通過修正版；完成 Node、Chrome、WebKit、格式、生成同步及 ZIP 內容一致性驗證。網站快取版本由 v30 升至 v31；更新本機交付包與文件，發布維持另行操作。
