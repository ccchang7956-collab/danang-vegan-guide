# 手機旅行流程與菜單資訊改版

使用者於 2026-10-16 批准前次提出的部署、手機驗收、當日時段、菜單價位、三餐首選與備援，另要求完整手機 UI/UX 優化。

## 設計

沿用既有綠色靜態旅行指南。相較純 CSS 縮排或完整改寫，採保留控制項 ID 的漸進改版，避免破壞離線、收藏及 GPS 的現有行為。

- 附近搜尋常用區只放搜尋、距離參考、半徑、定位及全素。用餐時間、區域、飲食細類和營業查核放同一個原生 details；有效條件仍以可移除按鈕顯示。列表/地圖操作集中，縮短到結果的距離。
- 餐廳卡片依序為分類/距離、名稱、精簡評分、所選日期時段、重要風險、地址、導航與地圖等操作。評分來源、查核日期、每週時段移到詳細資料，店家風險與地址衝突保持直接可見。
- 每張卡無論有沒有填時間，都顯示所選日期的每週表；有填時間才加狀態推估，保留非即時與最後點餐提示。
- 每餐顯示首選與備援、預計時間、相關地標、站內看店家、導航。單一備選明示未確認獨立備援；巴拿山園內餐不列確認首選。
- 菜單研究涵蓋全部 46 筆記錄，僅刊登官方可核對且適用分店的餐點及價格。沒有可靠資料明示待確認，不套用其他分店。菜單不等同全素認證；菜單查核日期與店家查核日期分開。
- 統一查看結果的焦點/鍵盤收合；每種地圖入口都有返回列表，從卡片來則可返回原卡。切頁恢復合理的焦點與閱讀位置。
- 手機安全區、觸控區、縮放文字、窄螢幕及橫向均驗證，盡可能加 WebKit 引擎測試；不得把模擬當作實體 iPhone 驗證。
- 部署既有 GitHub Pages 專案，發布前完成本機測試、更新離線版本及 ZIP；發布後以正式 URL 核對內容及離線更新。

## 驗收

核心時間邊界及當日表、菜單來源/價格、三餐角色；320/393/430px 及橫向不溢出，觸控與焦點；搜尋、收藏、地圖返回、離線、新版還原回歸。外部菜單來源逐筆保留。實體 iPhone 操作若無裝置存取則交付明確待驗步驟，不宣稱已完成。
