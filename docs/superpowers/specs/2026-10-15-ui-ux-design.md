# 隨行指南 UI／UX 優化設計

依使用者「按照 review 優化，順序由代理規劃」的授權執行。

採用既有靜態 HTML／CSS／JavaScript，沿用米白深綠視覺；新增獨立 UX 模組管理呈現偏好、收藏、採買清單、圖片對話框和導覽。核心搜尋、距離與地圖維持 app.js／core.js 管理。

順序：搜尋即時摘要與可操作空狀態 → 保留條件的全素切換與摘要 → 點餐操作前移 → 手機列表／地圖模式與精簡卡片 → 導覽返回、距離基準與排序 → 換匯／補給與常駐更新提示 → 收藏採買與樣式整理。

列表手機預設顯示，桌面維持並排；每日保留行程主軸。精簡卡片仍直接呈現飲食、地址衝突、休息日與其他風險。toast 僅用明確動作，搜尋數字持續顯示。全素切換保留其他條件，重設有獨立入口。點餐優先放大，複製明示越南文。圖片改站內對話框。收藏與已買使用本機儲存，儲存失敗仍可當次使用；GPS 不持久化。URL 記錄頁別和日期並支援返回。越南日期落在旅行期間才自動選日。

比較方案：僅改文字不足以解決列表距離；整站重寫增加回歸風險；採用既有核心加 UX 模組，能完整改善操作並保留離線架構。

驗證：更新行為改變的既有測試，新增搜尋回饋、篩選切換、列表模式、導覽與儲存備援的有意義測試；執行 Node 與真實 Chrome 瀏覽器檢查。更新 service worker 版本、README 與部署 ZIP。不上傳或部署。
