## 使用體驗

純靜態網站，可直接放 GitHub Pages，不需 API 金鑰或建置。主入口 index.html，附本地樣式、程式、資料及離線快取檔案。手機以單欄卡片閱讀，桌面可並列地圖和列表。底部固定每日行程、附近素食、換匯所、點餐卡四個入口，適配 iPhone 安全區域；文字至少 16px，主要觸控區至少 44px，不禁止縮放。

每日行程由 10/21–10/25 切換，顯示當天景點、住宿、航班、原行程時間與附近餐廳。景點、飯店與餐廳分別標示，點擊列表可在地圖選取；地圖點位可查看卡片及開 Google Maps 導航。連線不足時列表和地址仍可閱讀。

附近素食顯示全部經查證餐廳，可搜尋、依區域或全素程度篩選。定位只在使用者點擊後要求，成功時依直線公里數排序；不宣稱步行／行車時間。拒絕定位、逾時或不支援時可改用當天景點／住宿作參考位置。提供再次定位與清楚的目前參考位置。座標不足的店家仍可查地址導航，但不參與虛假的最近距離排名。

點餐卡有繁體中文、英文、越南文：不吃肉魚海鮮、蛋奶、蜂蜜、魚露、蠔油及動物高湯；接受蔥蒜。可放大給店員看和複製。

新增「換匯所」底部入口，顯示 TWD、USD 兌換越南盾的合法銀行／已公告授權櫃檯。依所選行程日期或 GPS 排序，標示銀行層級幣別證據、分行現鈔庫存仍需確認、可查證地址與座標、官方來源、電話（有來源時）及 Google Maps 導航。幣別篩選不可把未公開名單的授權櫃檯誤標成可收某幣。只有來源可追溯的座標才放入互動地圖；地址可查但座標無法核實的點保留導航，不參與最近距離排序。以越南國家銀行的現行外匯代理規則與官方銀行／商場資料為準；機場或金店若無法核驗個別營運者的授權，不列入已確認據點。頁面提醒旅客先向分行確認當日現鈔服務、幣別、面額、匯率、費用和營業時間。

## 餐廳研究與資料

三個分區研究：峴港市區山茶、海灘五行山、會安及郊區。收錄數量以可靠來源為準，不為湊數加入不明店。逐店保留名稱、地址、來源、查證日期、全素分類、點餐注意、營業時間可信程度與座標可信程度。搬遷使用新版可靠地址；有衝突則標示。全素店、素食店可做全素、葷素店可做全素、待確認分開呈現。預設優先全素店；不可把「chay」或「vegetarian」直接當 vegan。

附近的定義依真實參考點距離，不把峴港店誤當會安／美山／巴拿山步行可達。園區餐廳若只有區域定位，標示約略點位；巴拿山全素條件有爭議，提供明確確認提示與現場求助方式。

## 技術與失敗處理

Leaflet 1.9.4 作地圖，保留開源授權和底圖 attribution。所有相對路徑支援 GitHub Pages 子目錄。地圖庫與底圖連線失敗不阻塞文字；提供開啟當天 Google Maps 查詢。靜態資料不依賴即時外部 API。服務工作執行緒僅快取本站及本地地圖程式資產，不大量下載第三方地圖圖磚；首次成功開啟後可離線讀文字，底圖與導航需網路。不收集或上傳使用者 GPS，僅在瀏覽器記憶體使用。
