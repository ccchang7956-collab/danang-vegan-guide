# Grab 查核 Implementation Plan

**Goal:** 為全部 46 家餐廳加入可追溯的 Grab 資訊及篩選。

**Architecture:** research JSON 作為唯一來源，由 Python builder 驗證並加入每店 grabInfo。core.js 負責狀態與篩選，app.js 共用卡片與複製事件，ux.js 管理條件摘要及重設。

**Tech Stack:** 現有 Python、原生 JavaScript、Node test、Playwright；無新增依賴。

## Global Constraints

- 不限飯店、不猜 merchant ID、不把查無資料寫成沒有 Grab。
- 每筆來源與日期分開保存；舊證據不列為可確認現況。
- 歇業不提供外送動作；一般營業時間不代表外送接單時間。
- 修改 bundled 檔案同步升 sw.js v24。
