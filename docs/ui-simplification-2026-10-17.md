# UI／UX 資訊分層優化交付記錄

本輪依使用者確認的設計，整理整站資訊層級與手機操作。沿用米白、深綠與五項主要功能，優先減少找餐廳前的閱讀負擔。

## 可見變化

- **每日行程**：先顯示日期與路線，再安排用餐；新增用餐、餐廳搜尋與地圖捷徑。餐廳參考位置、半徑、時間與搜尋集中在可展開工具區。手機列表排在地圖前，桌面行程使用雙欄。
- **找餐廳**：搜尋、參考地標、距離同組；常用全素、有 Grab、收藏集中在同一列。排序與列表／地圖集中到結果區；減少重複的「查看結果」入口與長段說明。桌面搜尋使用三欄。
- **店家卡片**：飲食、距離、時段、地址及必要警告直接可見。導航、官方 Grab、收藏為主動作；菜單、聯絡、Google、地圖定位及查核集中在店家詳情。
- **換匯**：定位與日期條件整併；距離和完整查核說明放入用途指引，保留分行受理提醒。卡片仍顯示幣別資料等級、服務時段及聯絡限制。
- **補給**：資料日期與離線說明可展開，商品來源集中在成分與選購提醒，複製越南文與已買到仍直接可用。
- **點餐**：保留立即放大／複製；補上彈窗關閉的明確焦點還原，支援關閉按鈕與 Escape，修正 WebKit 和 Chrome 的原生行為差異。
