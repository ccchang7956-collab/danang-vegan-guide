# 定位、排序與手機資訊呈現修正（本機 v32）

## 修正結果

- 餐廳與換匯共用 GPS 品質判斷：距峴港中心超過 150 km、精度超過 1000 m、無效座標或缺少有效精度時，列表、結果數、摘要及地圖一致顯示定位待更新；重新定位成功或明確改用行程／地標後恢復。已選換匯手動地標不受附近頁的新定位覆寫，每日行程地圖也不受無效 GPS 影響。GPS 不寫入儲存空間。
- 排序明確分成「供餐時段優先」「距離優先」「全素優先」。預設供餐時段優先沿用查核／時段判斷；距離與全素選項優先順序與文字一致，無座標備選另列。用 `sortVersion: 2` 區別新舊查詢，舊版 `distance` 會遷移為原本實際採用的推薦排序；新版明確距離選項可重載還原。
- 一般搜尋有用餐時間、採供餐優先排序時，結果分為可用餐、需確認、其他時段、位置待確認；每組完整展開。距離／全素排序維持跨供餐狀態排序，避免分組破壞順序。
- 附近搜尋摘要日期只出現一次；清楚區分有距離資料與位置待確認數量，有限範圍與明確排序仍顯示。預設未填時間時省略未使用的供餐排序說明。
- 換匯服務時間移到導航前，與重複的確認提醒合併。AEON 保留完整商場時間及「櫃檯當日服務時間另確認」說明。
- 列表／地圖切換整合到餐廳結果標題列，換匯結果工具列縮減空白；保留字級與 44px 操作目標。390×844 並額外增加 34px 底部佔位時，首張餐廳及換匯導航仍完整位於底部導覽列上方。
